# 📊 Olist 电商数据分析项目

## 项目简介
本项目基于 Olist 巴西电商公开数据集，使用 Python、SQL 和 Excel 进行了全面的业务分析。旨在通过数据挖掘揭示销售趋势、用户价值及品类表现，并搭建交互式看板为业务决策提供支持。

## 核心分析结论
- **销售趋势**：识别出月度 GMV 增长/下降趋势及季节性波动规律。
- **品类表现**：明确了贡献核心 GMV 的 TOP10 品类。
- **用户价值**：通过 RFM 模型将用户分层，定位了高价值用户群体。

## 技术栈与工具
- **数据分析**：Python (Pandas, Matplotlib)
- **数据提取**：SQL
- **数据清洗与报表**：Excel (数据透视表, VLOOKUP)
- **数据可视化**：Power BI (交互式看板)

## 分析流程与方法论
1. **数据清洗**：处理缺失值、异常值及时间格式统一。
2. **漏斗分析**：分析用户从浏览到下单的转化情况。
3. **同期群分析**：评估不同周期用户的留存与复购间隔。
4. **用户分层**：基于 RFM 模型划分用户价值等级。

## 可视化看板
使用 Power BI 搭建了交互式经营看板，包含月度 GMV 趋势、TOP10 品类排名、用户价值结构环形图及日期切片器。
